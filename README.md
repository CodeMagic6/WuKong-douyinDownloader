# WuKong 视频下载

抖音 / B站 视频下载工具。粘贴链接自动下载，支持合集、收藏夹、UP主主页批量提取。

---

## 一、普通用户：下载即用（推荐，免安装）

### 准备工作

1. 在本项目的 **Releases** 页面下载最新的压缩包。
2. **解压**到任意文件夹（右键压缩包 →「解压到当前文件夹」）。
   > ⚠️ 不要直接在压缩包里双击运行，一定要先解压。

### 第一次使用

1. 双击 **`双击启动.bat`**。
2. 如果 Windows 弹出蓝色的「Windows 已保护你的电脑」：
   点 **更多信息** → **仍要运行**。
   （这只是因为程序没有购买数字签名，属于正常提示。）
3. 等几秒，浏览器会**自动打开**操作界面。
   如果没有自动打开，自己打开浏览器访问：**http://localhost:9090**
4. **登录**（下载前必须先登录）：
   - 点页面顶部 **「抖音: 未登录」**，会弹出一个浏览器窗口显示抖音登录页；
   - 用手机抖音 App **扫码**，或手机号登录；
   - 登录成功后窗口自动关闭，状态变成 **「已登录」**。
   - B站同理：点 **「B站: 未登录」** 扫码登录。
   - 登录状态会记住，下次不用重复登录。
5. **下载视频**：
   - **手动**：复制视频链接，粘贴到输入框，点「添加下载」；
   - **自动**（推荐）：点开底部「设置」→ 打开「剪贴板捕获」，之后**复制链接就会自动填入**；再打开「捕获后自动下载」，复制即开始下载。
6. 视频保存在软件文件夹里的 **`downloads`** 文件夹，也可以在「设置」里改成自己的目录。

### 日常使用

- 再次使用：重新双击 **`双击启动.bat`** 即可。
- 用完直接**关掉网页**，程序会自动退出。
- 想立刻退出：双击 **`停止.bat`**。

### 遇到问题

| 现象 | 怎么办 |
|------|--------|
| 杀毒软件 / 360 报警 | 程序没买签名，添加信任即可，不会影响使用 |
| 双击后没反应、网页没打开 | 手动打开浏览器访问 **http://localhost:9090** |
| 提示端口被占用 | 双击 `停止.bat` 再重新启动；仍不行就重启电脑 |
| 显示「已登录」但下载失败，或想换账号 | 点状态栏「已登录」旁边的 **「清除」** 按钮，再重新扫码登录 |
| 页面显示「服务器断开」 | 双击 `停止.bat`，然后重新双击 `双击启动.bat` |
| 想彻底清空登录信息 | 点抖音 / B站 状态栏的 **「清除」** 按钮 |

## 二、功能

| 功能 | 说明 |
|------|------|
| 扫码登录 | 抖音、B站 各一个按钮，扫码即登录，无需手动设置 |
| 清除登录 | 抖音 / B站 可分别清除登录，方便换账号 |
| 单视频下载 | 粘贴链接自动下 |
| 合集 / 收藏夹 / UP主批量下载 | 自动翻页扫描全部视频 |
| 剪贴板捕获 | 复制链接自动识别填入 |
| 实时进度 | 速度、剩余时间、百分比 |
| 并发控制 | 同时下载 1-10 个 |
| 自定义下载目录 | 保存在自己想放的地方 |

## 三、开发者：从源码运行

```bash
git clone https://github.com/CodeMagic6/WuKong-douyinDownloader.git
cd WuKong-douyinDownloader
npm install
node server.js
```

浏览器自动打开 http://localhost:9090

### 自行打包成免安装版

```bash
npm install          # 若改了代码
npx playwright install chromium   # 确保本机有 Chromium
npm run build        # 生成 dist/ ，内含 exe + 内置浏览器
```

打包完成后，把整个 `dist` 文件夹压缩发给用户即可，对方解压后双击 `双击启动.bat`。
打包前会自动清理 `settings.json`、日志、下载内容等个人状态，不会泄露你的信息。
